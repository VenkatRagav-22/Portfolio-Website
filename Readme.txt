🧰 Tech Stack

HTML5 (Semantic Structure)

Custom CSS3 (Utilizing a clean, dark-mode theme for visual impact)

Vanilla JavaScript (Interactivity and DOM manipulation)

GSAP (GreenSock) & ScrollTrigger (For smooth, engaging, scroll-based section reveal animations)

Google Fonts (Inter and DM Serif Display)

Fully Responsive Design

✨ Key Features

Minimalist Dark Mode Aesthetic: A modern, focused visual experience designed for clarity.

Engaging Scroll Animations: Sections smoothly fade in and move up as the user scrolls, powered by GSAP.

Structured Content: Dedicated sections for Projects, Journey (personal story/pivot), Experience (timeline), and Contact.

Interactive Contact: Includes a click-to-copy functionality for the email address.

Custom Navigation: Simple, elegant sticky navigation for seamless scrolling between sections.
